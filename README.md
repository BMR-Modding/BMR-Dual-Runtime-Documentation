# BMR Dual Runtime Documentation

BMR guides and translation references for FUSE and RailForge dual-runtime mods.

Private BMR development repository. This import is a source snapshot, not a new game-tested release.

## Contents

- Workspace source: [Duality mode documentation](<Duality mode documentation/>)



## Development and installation

Read each project's existing README, manifests and build/test scripts for requirements and status. Original project folder names and file bytes are preserved. Installed snapshots are kept separately from development sources and may contain local edits.

Some build scripts still require the original workspace layout, locally installed Railroader/Unity/runtime dependencies, or companion BMR projects. A clean-clone build has not been established by this repository setup. Game and third-party assemblies, local settings, caches, build outputs and release ZIPs are excluded. Existing source attribution is retained; no new license is assigned.

Use separately prepared release packages for installation. Do not copy this repository wholesale into the game's Mods folder.
